# Порядок сдачи и проверки

Порядок взят из актуального README iu5git/Web, раздел ЛР-1; исторический заголовок «2024» сохранён в репозитории курса 2026.

1. Тема: транспорт, вариант 29, расчёт экономии топлива при использовании круиз-контроля.
2–4. Три исправленных фрейма Figma: лента, добавление, плитка. SVG подготовлены; требуется импорт в исходный файл Figma.
5–7. Те же три страницы приложения.
8. Референс Яндекс Go.
9. CSS: точные цвета, hover и форма карточек.
10–12. В браузере Network показать GET плитки с диапазоном, GET ленты с ID и next=true, GET draft без ID. Подготовленные HTTP-фрагменты — реальные ответы, не скриншоты DevTools.
13. Response: URL картинок и видео MinIO.
14. Коллекция с отдельными латинскими ключами .jpg/.mp4.
15–17. Использование медиа в трёх шаблонах.
18. Роуты и три GET контроллера.
19. Числовая фильтрация и выбор следующего автомобиля.
20. Дополнение по запросу: поставить/снять лайк и пояснить POST/303, cookie и сохранение JSON. Для строгой защиты основного задания отключить расширение: FUEL_CONSUMPTIONS_STRICT_LAB1=true.

Контроль: одна коллекция; 4 опубликованных, 1 черновик, 1 удалённый; два числовых предметных поля; отсутствие JS и БД; нижняя навигация; description в две строки, «Ещё» через CSS; в плитке только расход; фото и видео раздельными полями; «Далее» отключена.

MinIO проверен в Docker: локально собранные образы из официальных исходников, восемь объектов в бакете fuel-consumptions. Код подготовлен в отдельной ветке lab1-fuel_consumptions репозитория cruisecontrol---back. Перед окончательной сдачей вписать ФИО/группу, импортировать SVG в Figma и сделать реальные снимки Network.
