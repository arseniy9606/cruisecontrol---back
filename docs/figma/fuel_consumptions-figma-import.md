# Исправленные экраны для Figma

Три SVG содержат отдельные редактируемые тексты, фигуры, иконки и встроенные фотографии. Они подготовлены из расположения элементов работающего приложения, а не из растрового снимка целиком.

Откройте исходный файл Figma и перетащите fuel_consumptions-feed.svg, fuel_consumptions-draft.svg и fuel_consumptions-tiles.svg на холст. Разгруппируйте импортированные объекты при необходимости. Назовите фреймы «Лента автомобилей», «Добавление автомобиля», «Плитка автомобилей». Для мобильного просмотра используйте фрейм 430×932 с вертикальным прокручиванием для плитки и добавления. Нижнюю навигацию зафиксируйте в пределах фрейма.

Лента — статический макет с постером, настоящее видео работает в приложении. Файловые поля — макеты системных элементов. Подключение прототипа: вкладки ведут к соответствующим фреймам, плитка — к ленте, иконка следующего — к варианту ленты.

Сохраните исходные экраны на отдельной странице «До исправлений», чтобы показать преподавателю замечания. Эти SVG подготовлены локально; исходный файл Figma ещё не изменён.
