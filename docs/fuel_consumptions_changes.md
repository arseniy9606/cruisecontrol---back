# Изменения относительно ЛР1

| ЛР1 | ЛР2 |
|---|---|
| Карточки в Go-массиве | Карточки в PostgreSQL |
| Лайки в коллекции и JSON-файле | Лайки — строки таблицы связи |
| Дополнительный POST лайка | Только чтение лайков, POST отсутствует |
| Кнопка «Далее» отключена | Создание черновика через GORM |
| Введённые поля не сохраняются | Публикация сохраняет описание, бак и расход |
| Нет удаления | Изменение статуса через SQL UPDATE без ORM |
| Лента выбирает элемент массива | Запрос PostgreSQL с LIMIT 1 |
| Фильтрация массива | SQL WHERE/BETWEEN через GORM |
| Статусы в коллекции | CHECK в БД и проверки запросов |
| Нет ограничений БД | FK RESTRICT, UNIQUE лайков и частичный UNIQUE черновиков |
| Только MinIO | PostgreSQL + Adminer + MinIO в отдельных контейнерах ЛР2 |

Оформление и медиа исходной лабораторной сохранены, новые формы работают без JavaScript. Запасные фото/видео размещены на Go-сервере. История и файлы папки ЛР1 не изменялись.

Проверено: создание и публикация в браузере, логическое удаление через Adminer и приложение, просмотр удалённой карточки с 404, отображение изменений чисел и лайков из БД, штатные и недоступные медиа, отдельный черновик на пользователя, конкурентное создание, миграция и повторный запуск.

Это список выполненных изменений. Конкретные замечания преподавателя не были предоставлены, поэтому он не подменяет требуемый файл с ответами на фактические замечания.
