# ЛР4: запросы
Все URL полные: http://localhost:8086/api. В запросах создателя замените PASTE_JWT_HERE токеном из входа. Сначала выполните POST http://localhost:8086/api/users/login (creator / Lab4Demo123), затем создание, черновик, публикацию, ленту, лайк и выход. Число 11 в URL замените ID из создания. Выберите фото и видео из media заново, если клиент не нашёл относительный путь.
Для демонстрации гостя удалите заголовок Authorization: каталог вернёт 200, публикация 403. После выхода старый JWT также даст 403 для изменений. Токены в файлы не сохранены.
