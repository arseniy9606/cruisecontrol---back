# Показ лабораторной работы 3

В коллекциях Insomnia и Postman все URL записаны полностью, без переменных окружения. Базовый адрес: http://localhost:8085/api.

В адресах публикации, лайка и удаления пример ID — 11. После создания автомобиля возьмите id из ответа и впишите его числом в адрес соответствующего запроса. Автоматическая подстановка удалена по замечанию преподавателя.

Порядок показа: список с фильтром; создание с фото и видео; черновик; публикация; лента; следующая карточка; лайк; удаление; регистрация. Перед повторным созданием удалите оставшийся черновик; для повторной регистрации смените login.

Для создания повторно выберите файлы media/cars_sedan.jpg и media/cars_sedan.mp4, если проект перенесён на другой компьютер.

Файл с исправлениями и пояснениями: docs/lab3_corrections.doc.
